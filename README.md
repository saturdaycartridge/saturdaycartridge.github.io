# saturdaycartridge.github.io

Website for Saturday Cartridge, published with GitHub Pages from the `main` branch. Static HTML and CSS,
no build step: edit the files and push.

- `index.html` - home page and packs
- `contact.html` - contact and support (the address the Asset Store profile links to)
- `styles.css` - all styles
- `assets/` - logo (`favicon.svg`, `profile-512.png` for the Asset Store profile), images, social preview

Preview locally: `python3 -m http.server 8742 --directory .` and open http://localhost:8742
